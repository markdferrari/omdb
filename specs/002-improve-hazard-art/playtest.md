# Artwork playtest record

No human review or first-time full-sequence session has been conducted for this feature.
Automated tests and agent inspection of rendered images do not satisfy player review.

## Representative interaction protocol

Launch the art fixture using quickstart. Use actual hazard deaths to create bodies.
For each row in [representative trials](evidence/representative-trials.csv), restart fresh,
arrange the named condition, record view/window/build, perform the interaction, then fill
actual outcome and defects. Each case requires ten consecutive successful repetitions
with keyboard and a physical controller. Cycle through all four normal isometric views;
include muted warning/jam judgments. Missing outcomes remain UNVERIFIED.

## Recognition and atmosphere protocol (Phase 4)

Recruit five people unfamiliar with the new artwork. Fill all 60 rows in
[recognition.csv](evidence/recognition.csv) at 1280×720 with trap-name labels hidden.
Pass: ≥54/60, ≥18/20 per hazard. Restore normal cues, mute audio and separately record
for every reviewer/view: active versus jammed, anvil footprint before impact, and safe
versus exposed routes. All must be correct for acceptance.

After five minutes playing, record each reviewer description, coherence rating 1–5,
help requests, misunderstood rules, jump judgment and placement frustration.
Pass: ≥4/5 reviewers describe gothic/macabre testing and rate coherence ≥4/5.

## Full sequence protocol (Phase 5)

Five first-time slice sessions; disclose any earlier fixture exposure. For each record
input, platform/build, completion time against 20–30 minutes, help requests,
misunderstood rules, jump judgment, placement frustration and defects/fixes/retests.
